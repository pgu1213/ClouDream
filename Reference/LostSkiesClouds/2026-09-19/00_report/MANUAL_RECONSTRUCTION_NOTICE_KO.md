# 수작업 복원 코드에 대한 필수 고지

`01_reconstructed`의 파일은 게임 제작사가 작성한 원본 C# 소스가 아니다. Unity IL2CPP가 생성한 네이티브 코드와 Cpp2IL ISIL, 타입 메타데이터, 직렬화 데이터를 사람이 대조하여 작성한 **소스 형태의 수작업 복원본**이다.

## 무엇이 비교적 확실한가

- 객체 필드 오프셋에 대응하는 필드 읽기와 쓰기
- 분기 조건, 루프 경계, 상수, 배열 인덱스
- Cpp2IL이 이름을 복구한 직접 호출
- 6개 구름 노이즈 레이어의 순서
- 프리셋 전환 중 coverage, raininess, boss-fight 값의 보간식
- VFX 속성 존재 검사와 실제로 전달하는 값

## 무엇이 원본과 다를 수 있는가

- 지역 변수명, 주석, 공백, 메서드 분리 방식
- 컴파일러가 인라인한 한 줄 프로퍼티/메서드 호출의 원래 형태
- 최적화로 합쳐진 `Update`와 `UpdatePostExposure`의 원래 호출 형태
- 이벤트의 소스 코드 표기 방식
- 네이티브 가상 호출 슬롯만 남고 이름이 직접 복구되지 않은 일부 호출
- null 검사와 예외 처리의 원래 C# 문법

## 신뢰도 표기

- **HIGH**: ISIL의 필드 오프셋, 분기, 상수 및 타입 선언이 서로 일치한다.
- **MEDIUM**: 실행 의미는 강하게 뒷받침되지만 원래 C# 문법이나 호출 경계가 최적화로 사라졌다.
- **LOW**: 주변 타입과 사용 맥락으로 추정했으며 직접적인 이름 복구가 불완전하다.

이 코드는 분석·학습용 참고 자료다. 그대로 프로젝트에 복사해 컴파일되는 것을 목표로 하지 않으며, 원본 소스라고 재배포하거나 단정해서는 안 된다. 판단이 필요한 경우 같은 이름의 `03_isil_evidence` 파일을 1차 근거로 사용한다.
